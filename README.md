# João Vitor Messias

**Backend Developer · TypeScript / Node.js · Python · AI integrations**

I build APIs and applications that connect business rules, databases and external services. My main interests are backend engineering and applied AI: turning a problem into a working flow, understanding where it can fail, and making its behavior easier to test and explain.

I'm based in Brazil and hold a degree in Systems Analysis and Development. I'm interested in junior backend and software development opportunities.

## Selected projects

| Project | What it does | Engineering focus |
| --- | --- | --- |
| [DocTrace](https://github.com/joaovitormessias/doctrace) | Answers questions about accounting PDFs using retrieved document excerpts. | TypeScript, Express, PostgreSQL/pgvector and n8n; input validation, retrieval and source-ID checks. |
| [Psychological Office](https://github.com/joaovitormessias/psychological_office) | Models patient records, appointments and consultation notes. | Python, Django REST Framework and PostgreSQL; role permissions, record ownership and atomic writes. |
| [Payment System](https://github.com/joaovitormessias/sistema-pagamentos) | Models orders, payment records and price-drop notifications. | Django REST Framework and Celery; nested updates, transactions and background-task boundaries. |
| [CapiChat](https://github.com/joaovitormessias/chat-real-time) | Supports private conversations, image messages and online presence. | Node.js, MongoDB, Socket.IO and React; authenticated sockets and asynchronous UI state. |
| [Arthorias](https://github.com/joaovitormessias/arthorias) | Maps camera-detected hand landmarks to robotic-hand servo commands. | Python, OpenCV, MediaPipe and Arduino; computer vision and hardware integration. |

These are portfolio and learning projects. Their READMEs describe setup, design decisions, tests and remaining limitations.

## How I approach development

I enjoy tracing a feature from its input through validation, state changes and persistence. My projects explore questions such as who may access a record, when a background job should run, and how an asynchronous response affects the current screen.

For code examples, start with [consultation ownership](https://github.com/joaovitormessias/psychological_office/blob/main/backend/consultas/views.py), [socket authentication](https://github.com/joaovitormessias/chat-real-time/blob/main/backend/src/lib/socket.js), or [document-source validation](https://github.com/joaovitormessias/doctrace/blob/main/backend/src/services/document-answer.service.ts).
